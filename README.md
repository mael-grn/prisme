# Prisme

This project's goal is to allow users to create and manage their own website content. 
While all other website creation platforms are oriented over the design part, here it is more about managing the data you want to be displayed.
Originally built only for my own usage (portfolio), the use is now open for anyone who wants to share something!

## Getting started

The project is hosted and perfectly usable on [this website](https://prisme.maelg.fr).

However, if you ever wants to host it yourself, please follow online steps for self hosting next js projects.

This project being open source, you are also welcomed to fork it and host it on your own Vercel.
